# CodeAlpha Hangman Game

A simple text-based Hangman game built in Python as part of the CodeAlpha Python Programming Internship (Task 1).

## What it does

A classic word-guessing game played through the terminal:
- Picks a random word from a predefined list
- Player guesses one letter at a time
- Tracks correct and incorrect guesses
- Game ends when the word is fully guessed or 6 incorrect guesses are made
- Option to play again after each round

## Tech used

- Python (no external libraries)

## Concepts demonstrated

- `random` module for word selection
- Loops (`while`) for game flow
- Conditional logic (`if-else`)
- String and set operations
- Input validation
